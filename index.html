Upcoming

Authentication system implementation. JWT-based auth with refresh tokens, user registration/login, and role-based access control (Caregiver, Family, Provider, Admin).

Feb 24 – Mar 2, 2026
Upcoming

Android edge device setup and camera integration. Configuring AI SDK on-device, establishing camera input pipeline, and local SQLite event storage.

  • Camera input pipeline (USB/IP cam support)
  • Local SQLite database for offline event queuing
Week 4
Mar 3 – Mar 9, 2026
Upcoming

Event pipeline connecting edge devices to the cloud backend. Real-time sync service, message queue (Redis Streams), and event processing engine.

Key Highlights

  • Edge-to-cloud sync service (online: real-time, offline: queue)
  • Event processor (Python FastAPI) with message queue
  • Device heartbeat & online/offline status tracking
Week 5
Mar 10 – Mar 16, 2026
Upcoming

Fall detection AI model integration (MoveNet Thunder for pose estimation) and caregiver dashboard with real-time patient status cards.

Key Highlights

  • MoveNet Thunder (TFLite) on-device pose estimation
  • Fall detection algorithm: torso height drop >40% in <1s
  • React Native dashboard with patient status card
Week 6
Mar 17 – Mar 23, 2026
Upcoming

Priority-based alert system and Firebase Cloud Messaging push notifications. Critical fall alerts repeat every 2 min until acknowledged.

Key Highlights

  • 4-tier alert priority: Critical, Urgent, Warning, Info
  • FCM push notifications (iOS + Android)
  • Alert acknowledgement flow & escalation logic
Week 7
Mar 24 – Mar 30, 2026
Upcoming

AI-powered medication verification using computer vision. Object detection for pills, pill classification, and hand-to-mouth intake gesture recognition.

Key Highlights

  • Pill detection pipeline: Object Detection → Classify → Action Detection
  • Medication schedule management (CRUD, daily/custom times)
  • Adherence calculation: (Doses Taken / Scheduled) × 100%
Week 8
Mar 31 – Apr 6, 2026
Upcoming

Chronological activity log with event filtering and medication tracking UI. Caregiver can view all events, filter by type/date, and export PDF/CSV reports.

Key Highlights

  • Activity timeline with 9 event types (fall, medication, activity, system)
  • Filtering by date range, event type, and location
  • Weekly medication adherence percentage display
Week 9
Apr 7 – Apr 13, 2026
Upcoming

On-demand video clip capture system. 30-second clips around fall events (-10s before, +20s after), 10-second clips for medication events, stored on AWS S3.

Key Highlights

  • Rolling buffer for pre-event video capture
  • H.264 MP4 encoding at 720p, upload to S3
  • Presigned URL access (1-hour expiry, AES-256 encryption)
Week 10
Apr 14 – Apr 20, 2026
Upcoming

In-app video clip playback, false positive reporting, and offline resilience mode. Local AI detection continues without internet; events sync on reconnect.

Key Highlights

  • Clip viewer with download & false positive reporting
  • Offline mode: local detection + up to 1GB clip storage
  • Sync-on-reconnect: queue upload events oldest-first
